# ECommerce App
An e-commerce website using DummyJSON data

# Required to run
* Node.js [https://nodejs.org/en/download/]

# Installation 
* Clone using the web URL with `git clone https://github.com/hrDGT/ECommerceApp.git`
* Navigate into the project folder with `cd ECommerce App`
* Install dependencies with `npm install`

# How to run
* Run `npm run stat` to run the project in development mode
 
# For developers
* Run `npm run build` to create dist/ folder with production build
* Run `npm run lint` to check for lint issues
* Run `npm run lint:fix` to fix lint issues
* Run `npm run ts-check` to check fot TS issues

# Deploy
* Project is deployed. You can access it via https://hrd-ecommerce-app.netlify.app/
